# Campus Circuit

Student-only intent-based matching app.

## Local setup
1. Install [Node.js](https://nodejs.org) if you don't have it.
2. Copy `.env.example` to `.env` and fill in your Supabase Project URL and anon key.
3. Run:
   ```
   npm install
   npm run dev
   ```
4. Open the local URL it shows (usually http://localhost:5173).

## Deploy
See the deployment guide from your Claude conversation for step-by-step Vercel setup.
